# AI Student Impact Analysis Dashboard

## Project Overview
This project analyzes the impact of AI usage on students using an interactive Excel Dashboard.

## Tools Used
- Excel

## Dashboard Features
- KPI Cards
- Interactive Slicers
- Bar Charts
- Line Charts
- Scatter Plot
- Student Performance Analysis
